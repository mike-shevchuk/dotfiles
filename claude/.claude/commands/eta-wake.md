# /eta-wake — прогноз = обіцянка з перевіркою (Mike 20.11)

Mike 20.11: «команда /eta-wake, яка буде мати тогл і поки включена оновлює eta і контролить процес і пише цінну інфу і скільки часу я вільний, якщо все працює без мене, і операції, що плануються; в /night-audit вона включена постійно, поки триває, а замість вільний пише, що я сплю».

## Тогл (один файл, без пам'яті)
- Стан: `~/.claude/fleet-board/w<N>/eta-wake.on` — є файл = **ON**.
- `/eta-wake` → перемкнути; `on` → `touch`; `off` → `rm`; `status` → лише показати.
- `/night-audit` вмикає його на старті (`touch`) і не вимикає, поки в `night-audit-state.tsv` є `todo`/`doing`.
- OFF: `eta-wake.sh` одразу виходить («eta-wake: OFF»), цикл зупиняється сам.
- **Статуслайн ліда** (Mike 20.11: «якщо вона ввімкнена — вона має бути в статуслайні»): поки є `eta-wake.on`, рядок 3 починається з `⏰ ETA ON · 🟢 Ти вільний до ≈HH:MM` / `😴 Ти спиш до …` / `🙋 зараз чекає тебе`. Джерело одне — `bin/eta-free.py` (його ж кличе `night-progress.sh`).

## Поки ON — цикл (лід, без нових механізмів)
1. **Кожна відповідь Mike** закінчується запуском фоном (`run_in_background: true`): `~/.claude/fleet-board/bin/eta-wake.sh` — спить до найближчого `≈HH:MM` (останній рядок кожного треку в `w<N>/tracks.tsv`) і будить ліда. Один такий таймер одночасно: не запускати другий, поки перший живий.
2. **На пробудженні** (`ETA-DUE HH:MM: <треки>`):
   - `LEAD_SESSION=W<N> ~/.claude/fleet-board/bin/night-progress.sh` — бар аудиту (якщо йде), 👥 флот, 📋 далі, 🟢/😴.
   - Для кожного due-треку звірити ФАКТ: 📍 вікна, `dev-queue.md`, `pipeline-stamp.sh gates only=<PR>`, lock-каталоги.
   - Оновити: `track.sh <N> "<track>" "<step>" done` або новий крок/ETA `"≈HH:MM …"`. Зірвано → причина одним реченням + нова година.
   - Застрягло вікно / dev вільний з чергою / «🙋 LEAD» без відповіді → закрити як лід (send.sh), не чекати Mike.
   - Знову `eta-wake.sh` фоном.
3. **Що писати Mike** — лише цінне (≤ 8 рядків): що змінилось з минулого разу (done, зірвано + чому, нові 🙋), бар + 👥 рядок з `night-progress.sh`, `📋 далі` з годинами. Нічого не змінилось → один рядок «без змін, наступна перевірка ≈HH:MM».
4. **Останній рядок завжди** з `night-progress.sh`: `🟢 Ти вільний до ≈HH:MM (≈M хв)` — до першого кроку, що потребує Mike (проба / рішення), якщо все піде за планом. Під час `/night-audit` — `😴 Ти спиш до ≈HH:MM`. Чекає просто зараз → `🙋 зараз чекає тебе: …` з командою.

## Правила
- Години — лише годинник `≈HH:MM`, ніколи «≈30 хв» без години (Mike 19.11).
- ETA ставить той, хто планує: `track.sh` 6-те поле. Без ETA трек не будить — значить, ETA обов'язкові для кожного кроку флоту.
- Нічого не деплоїти й не мерджити через цей цикл; лише звірка, оновлення і передача кроків (ті самі ✅/⛔, що в лід-правилах).
