# /mine-grill — закрити мої блокери через модальне вікно

Mike 22.10: «добав команду /mine-grill яка буде теж через модальне вікно говорити зі мною і закривати блокери».
Mike відповідає у вікні з варіантами (+ своя думка через «Other») або в чаті — не перепечатує текстові блоки ([[feedback_questions_via_modal]]).

## 1. Зібрати (одна команда, не з пам'яті)
Сесія = поточна tmux-сесія (`tmux display -p '#S'`: `esp`, `W44`, `dotfiles`…); lead.py бере її сам, дошка — `~/.claude/fleet-board/<сесія в нижньому регістрі>/` (нижче `w<N>/` = ця тека). Блокери інших сесій не чіпати й не питати: це справа їхнього ліда (Mike 03.11: «має дивитись відносно даного tmux session, а не лізти в конкретний W44»).
`python3 ~/.claude/scripts/lead.py blockers --json` (+ `--json` ↔ `blockers <idx>` для одного вікна) і `python3 ~/.claude/scripts/lead.py footer`.
Беремо лише 🙋 «Блокуєш ТИ» (не 🧭 лід — це мій борг, закриваю сам ДО того, як питати Mike). Порядок — бали з `w<N>/priorities.tsv` (100 → 0).
Аргумент `$ARGUMENTS`: PUN-x / W42:N — лише його; порожньо / `all` — усі.

## 2. Перевірити кожен блокер ДО питання
- Відкрий brief вікна (`w<N>/briefs/<idx>.md` «Що потрібно від Mike») і progress; звір наживо факт, на якому стоїть питання (URL/команда/sha). Застаріле — прибери з brief/need-mike, Mike не питай.
- Те, що Mike може зробити лише руками (проба `jb2b …-try`, `! jb2b …`), — не питання: дай команду в тексті, у модалі лише «запустив / пізніше».

## 3. Текст над модалем (для кожної пачки ≤4 питань)
**3a. Картка фічі — ОБОВ'ЯЗКОВО перед першим питанням кожного PUN/PR** (Mike 03.11: «що таке notice … чому grill питання без контексту, це вже не вперше»):
- що це за фіча продуктовими словами: **хто → що робить → що бачить отримувач/користувач** (приклад: «Notice = responder/admin надсилає текст (push+SMS+email) ролям, групам чи юзерам своєї org, поза тривогою або під час неї; не чат і не тривога»);
- чим вона НЕ є (найближча плутанина: чат, тривога, notification);
- кожен внутрішній код/термін (`S1`, `G33`, `resolver`, `override`, `stamp`, назва поля) — розшифрований одним рядком при першій появі.
Джерело — TL;DR / «Було → стало» плану, не назва тікета.

**3b. На кожне питання** 3–5 рядків простими словами: **що сталось · факт з доказом · чому блокує (хто стоїть: W<N>:<idx>) · що зміниться після відповіді.** Без жаргону, без «див. вище».

**3c. Самоперевірка перед `AskUserQuestion`:** перечитай текст очима людини, яка не бачила плану. Є термін без розшифровки, або питання не можна зрозуміти без файлу плану → переписати, модаль не відкривати. У `question` модаля сам термін теж з глосою в дужках: «Notice (масове повідомлення в org): хто може надсилати у v1?».

## 4. Модаль — `AskUserQuestion`, ≤4 питання за раз
**Контекст живе ВСЕРЕДИНІ модаля** (Mike 03.11, вдруге за день: «де контекст перепиши щоб завжди давав мені контекст»). Поки модаль відкритий, текст над ним Mike може не бачити — картка в чаті НЕ рахується.
- `question` — 2–3 речення: що це за фіча/дія (глоса), факт, що вирішується. Кожен термін (census, IDOR, stamp, план так…) — з поясненням тут же.
- `preview` на кожному варіанті (single-select): міні-картка markdown 6–12 рядків — «Що це / Зараз / Після цього варіанту / Ризик / Хто що робить далі». Без preview модаль не відкривати.
- Дія Mike руками (команда) — повна команда і що вона робить прямо в `preview` варіанта «запустив».
- `header` ≤12 символів (`2379 дедуп`, `1923 env`).
- 2–4 варіанти: рекомендований першим з `(Recommended)`, у `description` — наслідок одним рядком (що зробить команда далі).
- Не додавай варіант «Other» — він є сам. Відповідь «Other»/уточнення → обговори в чаті, потім переформулюй.

## 5. Закрити кожну відповідь одразу
1. Передай вікну, що чекає: `~/.claude/fleet-board/bin/send.sh W<N>:<idx> "LEAD: Mike — <рішення>. <що робити далі>"` (довге → допиши в місію, вікну — вказівник).
2. Запиши: рішення плану → `## Grill (Mike, <date>)` у плані (`→ Mike: …`), «план так» → `~/.claude/fleet-board/bin/plan-approve.sh PUN-x <абсолютний шлях плану>` (пише в `plan-approvals.tsv` → ворота PLAN; вимагає ≥3 рядки «→ Mike:» під «## Grill» — таблиця не рахується, хай вікно допише рядки). Не дописуй у tsv вручну: 03.11 так обійшли перевірку grill; бали → `w<N>/priorities.tsv`; пауза → `state.json`.
3. Прибери рядок з `w<N>/need-mike.tsv`, онови трек `track.sh <N> "<track>" "<step>" run|done <pct>`.
4. Зовнішні дії (Linear/GitHub/Slack/prod) — лише якщо відповідь Mike прямо це дозволяє; інакше чернетка.
